# Фаза 4: Реализация

Прочитай этот файл и выполни всё что написано ниже.
Этот файл используется повторно — каждый раз Claude берёт следующую задачу из плана.

---

## Задачи (каждый раз)

1. Прочитай `CLAUDE.md` и `docs/PLAN.md`
2. Определи текущую задачу (первая незавершённая)
3. Используй `superpowers:test-driven-development` skill — сначала тест, потом реализация
4. После завершения используй `superpowers:verification-before-completion` — убедись что всё работает перед тем как считать задачу готовой
5. Обнови `CLAUDE.md` (добавь файл в "Уже реализовано", обнови текущий фокус)

## При ошибках

Используй `superpowers:systematic-debugging` skill — не угадывай, диагностируй.

## Завершение всей фазы

Когда все задачи из `docs/PLAN.md` выполнены: используй `superpowers:requesting-code-review` и обнови WORKFLOW.md (✅ Фаза 4).
