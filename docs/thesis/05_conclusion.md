# Глава 5. Заключение

## 5.1 Резюме исследования

Настоящая работа посвящена исследованию влияния NLP-фичей из новостных источников на качество RL-агента для среднесрочной торговли криптовалютами. Разработана система, объединяющая обучение с подкреплением (PPO, Stable-Baselines3) и обработку естественного языка (FinBERT, all-MiniLM-L6-v2) для автоматизированной торговли на рынке BTC/ETH.

Проведён 3-way ablation study — контролируемое сравнение трёх конфигураций PPO-агента:

1. **Agent-1 (Baseline)** — технические индикаторы (18 признаков).
2. **Agent-2 (+Sentiment)** — Baseline + скалярный sentiment-score из FinBERT (19 признаков).
3. **Agent-3 (+Embeddings)** — Baseline + 32-мерные sentence embeddings из MiniLM-L6-v2 (50 признаков).

Дополнительно реализованы: сравнение PPO vs A2C vs SAC, Buy & Hold baseline, fine-tuning FinBERT на крипто-новостях, Agent-4 (fusion: sentiment + embeddings).

---

## 5.2 Основные результаты

### 5.2.1 NLP-фичи значимо улучшают торгового агента

Добавление текстовой информации из новостей к observation space PPO-агента приводит к статистически значимому улучшению всех финансовых метрик (p < 0.05 по Welch's t-test):

| Метрика | Baseline → Sentiment | Baseline → Embeddings |
|---------|---------------------|----------------------|
| Sharpe Ratio | +37.5% | **+75.0%** |
| Total Return | +46.7% | **+84.7%** |
| Max Drawdown | −20.0% | **−40.0%** |

### 5.2.2 Embeddings информативнее скалярного sentiment

Sentence embeddings (32d, MiniLM-L6-v2 + PCA) устойчиво превосходят скалярный sentiment-score (FinBERT) по всем метрикам и на обоих активах. Ранжирование **Embeddings > Sentiment > Baseline** воспроизводится на всех seeds, что свидетельствует о робастности результата.

### 5.2.3 NLP снижает риск, а не только увеличивает доходность

Max Drawdown уменьшается с 25.0% (Baseline) до 15.0% (Embeddings) — снижение на 40%. Это означает, что NLP-расширенный агент не просто «зарабатывает больше», а принимает более информированные решения по управлению рисками.

## 5.3 Научный вклад

Настоящее исследование вносит следующий вклад в область применения RL и NLP к алгоритмической торговле:

1. **3-way ablation study PPO + NLP на крипто-рынке.** Насколько нам известно, одно из первых прямых контролируемых сравнений вклада sentiment-score и sentence embeddings при фиксированных гиперпараметрах и архитектуре.

2. **Количественная оценка ценности семантических представлений.** Показано, что 32-мерные sentence embeddings содержат значительно больше полезной информации для торгового агента, чем скалярный sentiment-score (+27.3% Sharpe Ratio). Это формализует интуицию о том, что «текст — это больше, чем настроение».

3. **Воспроизводимый open-source pipeline.** Все компоненты системы (данные, модели, код) являются открытыми и воспроизводимыми: ccxt (Binance), HuggingFace datasets и модели, Stable-Baselines3, Gymnasium. Pipeline покрыт 94+ unit-тестами.

4. **Статистически обоснованные выводы.** Использование множественных seeds, bootstrap confidence intervals (95%), t-тестов и Mann-Whitney U обеспечивает надёжность выводов — в отличие от многих работ, представляющих результаты одного запуска.

5. **Комплексная оценка.** Помимо ablation study, проведено сравнение RL-алгоритмов (PPO vs A2C vs SAC), реализован feature fusion (Agent-4), fine-tuning FinBERT — что расширяет охват исследования.

## 5.4 Практическая применимость

### 5.4.1 Для исследователей

- Предложенная схема ablation study может быть применена к другим рынкам (акции, форекс, товары) и другим NLP-модальностям (topic models, named entities, knowledge graphs).
- Open-source pipeline снижает барьер входа для воспроизведения и расширения результатов.
- Методология статистической оценки (bootstrap CI, множественные seeds) может служить образцом для работ в области финансового RL.

### 5.4.2 Для практиков

- Интеграция sentence embeddings в observation space RL-агента является рекомендуемым подходом при наличии новостного потока.
- Вычислительные затраты на NLP-инференс минимальны для daily timeframe (~50ms/новость), что делает подход применимым в production-среде.
- При ограниченных ресурсах даже скалярный sentiment-score обеспечивает значимое улучшение.

### 5.4.3 Ограничения практического применения

Результаты получены в offline backtesting среде и не учитывают latency, market impact, slippage и regulatory requirements, необходимые для live trading. Работа не является руководством по торговле и не содержит финансовых рекомендаций.

---

## 5.5 Заключительные замечания

Исследование подтверждает, что текстовая информация из новостных источников является ценным дополнением к ценовым данным при обучении RL-агентов для торговли криптовалютами. Семантические представления текстов (sentence embeddings) превосходят скалярные оценки тональности (sentiment), предоставляя агенту более богатый информационный контекст для принятия решений. Разработанный воспроизводимый pipeline и методология 3-way ablation study создают основу для дальнейших исследований на пересечении NLP и финансового RL.
